# Vidmetry

<img src="src-tauri/icons/128x128.png" width="80" height="80" alt="Vidmetry">

Vidmetryは、動画の画面領域と再生時間を切り取るWindows 11向けデスクトップアプリです。動画またはフォルダーを開き、プレビューを見ながら残したい範囲を決めて保存できます。フィルター、テロップ、複数動画の合成といった一般的な動画編集機能は持たず、切り取りに必要な操作だけをまとめています。

## このアプリの目的

Windows標準のフォトアプリでは、動画の開始位置と終了位置を変える時間トリミングはできますが、写真と同じように動画の上下左右を切り取ることはできません。画面領域を切り取るにはClipchampなどの動画編集ソフトを開き、素材をタイムラインへ配置して書き出す必要があります。

Vidmetryは、動画編集全般ではなく、この画面領域の切り取りを簡単に行うためのアプリです。プレビュー上の枠で残す領域を指定し、必要であれば再生時間もフレーム単位で調整します。設定はあらかじめ保存されるため、通常は動画を開いて範囲を決め、保存先を選ぶだけで作業が終わります。

Windowsフォトの動画編集については、[Microsoftの説明](https://support.microsoft.com/en-us/windows/apps/photos/edit-photos-and-videos-in-windows)も参照してください。

## 主な機能

- プレビュー上の枠をドラッグして、動画の上下左右を切り取る
- 座標と大きさをピクセル単位で指定し、縦横比も固定できる
- 動画の開始位置と終了位置をフレーム単位で調整する
- 再生、ループ再生、スクロール操作で保存前に内容を確認する
- 動画またはフォルダーを、エクスプローラーやドラッグ＆ドロップから開く
- フォルダー内の動画を一覧またはPage Up／Page Downで切り替える
- 元動画を残す「コピーして保存」と、確認付きの上書き保存を使い分ける
- Windowsのライト／ダークモードとアクセントカラーを反映する
- 日本語と英語を切り替える

動画の読み込み、プレビュー作成、切り取り、保存はPC内で完結し、動画を外部サーバーへアップロードしません。

## 画質と保存方法

動画の実際の画素を切り取る場合は、通常は映像の再エンコードが必要です。Vidmetryでは、再エンコードによる劣化をできるだけ抑えたい場合と、劣化を一切発生させたくない場合の両方に対応できるよう、三つの保存方法を用意しています。

### 互換MP4

一般的な端末やプレイヤーで再生しやすいMP4として保存します。この方式では映像を再エンコードしますが、H.264／H.265、CRF、エンコード速度、画素形式、フレームレートを設定できるため、画質、ファイルサイズ、互換性のバランスを用途に合わせて調整できます。音声のコピーまたは変換、音声ビットレート、字幕とメタデータの保持、Web再生向けの最適化も設定できます。

### 可逆保存

映像を可逆形式で再エンコードし、デコード後の画素を劣化させずに保存します。画面領域や再生時間を実際に切り取った動画を作りながら画質劣化を避けられますが、互換MP4よりファイルサイズが大きくなり、再生できるソフトも限られます。

### メタデータのみ

対応するH.264／HEVC動画では、映像データを再エンコードせず、表示する画面領域だけをメタデータとして記録できます。元の圧縮済み映像をそのまま維持するため画質劣化はありませんが、クロップ情報を解釈しないプレイヤーでは切り取りが反映されません。また、フレーム単位の時間トリミングとは併用できません。

保存方法と詳細設定は共通設定で選択し、動画ごとに同じ設定を繰り返す必要はありません。出力形式が元動画と同じ場合は、元動画を残すか上書きするかを保存時に選べます。

## 基本的な使い方

1. 動画またはフォルダーをVidmetryへドロップするか、選択ボタンから開きます。
2. プレビュー上の枠を動かして、画面に残す領域を決めます。
3. 必要であれば、画面下のフレーム列で開始位置と終了位置を調整します。
4. 再生またはスクロール操作で内容を確認し、「コピーして保存」または「保存」を選びます。

## 主なショートカット

| キー | 操作 |
|---|---|
| `Space` | 再生／一時停止 |
| `←` / `→` | 選択中の位置を1フレーム調整 |
| `Shift` + `←` / `→` | 開始／終了位置を10フレーム調整 |
| `Page Up` / `Page Down` | フォルダー内の前／次の動画へ移動 |
| `Ctrl` + `S` | コピーして保存 |
| `Ctrl` + `Shift` + `S` | 元動画へ保存 |
| `F11` / `Esc` | 全画面プレビューの開始／終了 |

## インストール

対応環境はWindows 11 x64です。[GitHub Releases](https://github.com/automachete/vidmetry/releases)から最新のセットアップEXEまたはMSIをダウンロードしてインストールしてください。

インストールすると、対応動画の「プログラムから開く」とフォルダーの右クリックメニューからVidmetryを起動できます。この連携は共通設定で無効にできます。
