Vidmetryは、動画の**画面に映す範囲**と**再生する範囲**を、見ながらすばやく切り取るWindowsアプリです。

動画編集ソフトを開いてプロジェクトを作り、タイムラインや書き出し設定と格闘したいわけではない。ただ、余計な映り込みや余白を消して、必要な場面だけ残したい——Vidmetryは、そんな作業をスマートフォンの写真アプリで切り取るような感覚で終わらせるために作っています。

フィルター、テロップ、エフェクト、複数動画の合成などはありません。動画を選び、残したい部分を決め、保存する。その一つの仕事に集中した軽量なツールです。

## Vidmetryでできること

- プレビュー上の枠を動かして、画面の必要な部分だけを残す
- 動画の先頭と末尾を、フレーム単位で正確に調整する
- 再生、ループ、スクロール操作で、切り取る範囲をその場で確認する
- 動画をアップロードせず、すべてPC内で処理する
- 通常のMP4、画質劣化を避ける可逆保存、再圧縮しない対応形式から保存方法を選ぶ
- フォルダー内の動画を順番に切り替えながら確認する

## 使い方

1. 動画またはフォルダーをVidmetryへドロップします。
2. プレビュー上の枠で、画面に残す範囲を決めます。
3. 画面下のフレーム列で、残したい開始位置と終了位置を決めます。
4. 再生して確認し、**コピーして保存**します。

元の動画は通常そのまま残ります。保存形式が元動画と同じ場合は、確認のうえで元動画へ上書きすることもできます。

## こんなときに

- 画面録画から、ウィンドウの枠や不要なUIを消したい
- スマートフォン動画の端に映り込んだものを切り取りたい
- 黒帯や余白を取り除きたい
- 長い動画から必要な場面だけを残したい
- フォルダーにある複数の動画を、一つずつ同じ感覚で確認したい
- 再圧縮による画質劣化を避けて保存したい

## 保存方法と画質

### 互換MP4

普段の共有や再生に向いた保存方法です。ほとんどの端末やプレイヤーで扱いやすいMP4として保存します。

### 可逆保存

切り取り処理による画質劣化を避けたい場合に使います。映像を劣化させずに保存する代わりに、ファイルサイズは大きくなります。

### メタデータのみ

映像そのものを再圧縮せず、表示する範囲だけを動画へ記録します。高速で元の映像データを維持できますが、この情報を無視するプレイヤーでは切り取りが反映されません。また、再生時間を切り取る場合には利用できません。

保存方法は設定画面で一度選んでおけば、以降は保存先を選ぶだけです。映像形式や画質を細かく調整したい場合の詳細設定も用意しています。

## Windowsに馴染む使い心地

- Windowsのライト／ダークモードとアクセントカラーを自動反映
- 日本語と英語に対応
- 対応動画の「プログラムから開く」とフォルダーの右クリックメニューから起動可能
- フォルダー内の移動、全画面プレビュー、保存などをキーボードでも操作可能
- 保存完了後、その動画を選択した状態でエクスプローラーを表示

## 主なショートカット

| キー | 操作 |
|---|---|
| `Space` | 再生／一時停止 |
| `←` / `→` | 選択中の位置を1フレーム調整 |
| `Shift` + `←` / `→` | 開始／終了位置を10フレーム調整 |
| `Page Up` / `Page Down` | フォルダー内の前／次の動画へ移動 |
| `Ctrl` + `S` | コピーして保存 |
| `Ctrl` + `Shift` + `S` | 元動画へ保存 |
| `F11` / `Esc` | 全画面プレビューの開始／終了 |

## インストール

対応環境はWindows 11 x64です。

[GitHub Releases](https://github.com/automachete/vidmetry/releases)から最新のセットアップEXEまたはMSIをダウンロードし、インストールしてください。

## プライバシー

動画の読み込み、プレビュー作成、切り取り、保存はPC内で完結します。編集する動画が外部サーバーへアップロードされることはありません。
