# Vidmetry

<img src="src-tauri/icons/128x128.png" width="80" height="80" alt="Vidmetry">

Vidmetryは、動画の画面領域と再生区間を、プレビューで確認しながら切り取って保存する、軽量なWindows向けデスクトップアプリです。

重たい動画編集ソフトの複雑な設定を操作する必要はなく、スマートフォンのフォトアプリのようにお手軽に切り取りができます。

Windows標準フォトの動画トリミングでは扱えない画面領域の切り取りにも対応しています。

また、Vidmetryでは保存時に再生互換性、ファイル容量、画質のどれを優先するかに合わせて保存方法を選べます。

## 使い方

1. 動画または動画フォルダーをVidmetryへドロップ（または選択）します。
2. プレビュー上の枠を動かして、画面に残す領域を決めます。
3. 画面下のフレーム列で開始位置と終了位置を調整します。
4. 再生またはスクロール操作で内容を確認し、「コピーして保存」または「保存」を選びます。

## Vidmetryでできること

- プレビュー上の枠をドラッグして、動画の上下左右を切り取る
- 座標と大きさをピクセル単位で指定し、縦横比も固定できる
- 動画の開始位置と終了位置をフレーム単位で調整する
- 再生、ループ再生、スクロール操作で保存前に内容を確認する
- フォルダー内の動画を一覧またはPage Up／Page Downで切り替える
- 元動画を残す「コピーして保存」と、確認付きの上書き保存を使い分ける

## 画質と保存方法

Vidmetryでは、再生しやすさ、ファイル容量、画質のどれを優先するかに応じて、三つの保存方法を選べます。普段の共有に使いやすいMP4、画素を保つ可逆保存、圧縮済みの映像をそのまま維持するメタデータのみの保存には、それぞれ次のような長所と短所があります。

| 保存方法 | メリット | デメリット |
|---|---|---|
| 互換MP4 | 多くの端末やプレイヤーで扱いやすく、画質、ファイルサイズ、互換性のバランスを詳細に調整できます。 | 映像を再エンコードするため、設定によっては追加の圧縮による画質劣化が生じます。 |
| 可逆保存 | 画面領域や再生時間を実際に切り取ったうえで、デコード後の画素を劣化させずに保存できます。 | ファイルサイズが大きくなり、再生できるソフトも限られます。 |
| メタデータのみ | 対応するH.264／HEVC動画を再エンコードせず、元の圧縮済み映像をそのまま維持できます。 | クロップ情報を解釈しないプレイヤーでは切り取りが反映されず、時間トリミングとも併用できません。 |

Windowsやスマートフォンの標準アプリでは再エンコードによる画質劣化を避けられませんが、Vidmetryでは多彩なオプションで画質を維持する方法を選べます。

## 主なショートカット

| キー | 操作 |
|---|---|
| `Space` | 再生／一時停止 |
| `←` / `→` | 選択中の位置を1フレーム調整 |
| `Shift` + `←` / `→` | 開始／終了位置を10フレーム調整 |
| `Page Up` / `Page Down` | フォルダー内の前／次の動画へ移動 |
| `Ctrl` + `S` | コピーして保存 |
| `Ctrl` + `Shift` + `S` | 元動画へ保存 |
| `F11` / `Esc` | 全画面プレビューの開始／終了 |

## インストール

対応環境はWindows 11 x64です。[GitHub Releases](https://github.com/automachete/vidmetry/releases)から最新のセットアップEXEまたはMSIをダウンロードしてインストールしてください。

インストールすると、対応動画の「プログラムから開く」とフォルダーの右クリックメニューからVidmetryを起動できます。この連携は共通設定で無効にできます。
