# Third-party notices

Vidmetry invokes FFmpeg and ffprobe as separate command-line sidecars. The binaries prepared by `scripts/setup-ffmpeg.ps1` are downloaded from the Gyan.dev Windows builds and are not stored in this repository.

- FFmpeg project: <https://ffmpeg.org/>
- Windows build distributor: <https://www.gyan.dev/ffmpeg/builds/>
- FFmpeg legal information: <https://ffmpeg.org/legal.html>

Before distributing a Vidmetry installer that bundles these binaries, review the exact build configuration and include all licenses, notices, and corresponding-source information required by that build.
